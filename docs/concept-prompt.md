## Final prompt

Use case: ui-mockup. Create polished concept art for a desktop web app called "SDM Time Manager", a very simple chess-clock inspired work timer for two responsibilities: "VD" with subtitle "SDM", and "SIT" with subtitle "SDM / Servicedesk". High fidelity flat UI design screenshot, landscape canvas. Warm off-white background, dark ink typography, subtle fine borders, restrained teal for active VD and muted amber for SIT. Main heading "Make time for both." Small Today label. Two spacious side-by-side timer cards with huge tabular numerals, VD active showing "02:42:18" remaining of 4h, SIT showing "03:30:00" remaining, clear large "Switch to SIT" control. A centered pause control underneath. A modest allocation strip with "Move 15 min" between roles. Below a clean notes section with role tags, a text input "What are you working on?" and two realistic short note rows. Small header controls for History and Settings. Include a small companion mobile layout to the right, same interface stacked. Professional accessible productivity tool, generous whitespace, no charts or dashboard clutter, no decorative photography. This is concept art before implementation.

## Implementation decision

After this concept was generated, the user selected count-up tracking and continuous elapsed time until pause or role switch. The built app replaces countdown budgets and allocation transfers with elapsed clocks and a daily time split.
