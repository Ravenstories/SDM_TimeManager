How your timer works

Choose one responsibility to start or switch. Time counts up until you pause, including during sleep or browser closure. The timer reconstructs elapsed time from saved timestamps.

Keys 1, 2 and 3 select the first three available responsibilities. Space pauses. Shortcuts do not run inside forms or dialogs and are not global desktop shortcuts.

Review past days using the date controls. Correct completed entries or choose an earlier stop time for a forgotten timer. Nothing is removed automatically.

Work and non-work totals are separate. Renaming or reclassifying a responsibility changes its entire history. Archive it to retain history without offering it for new tracking.

The device timezone determines calendar days. Changing timezone or the system clock can change wall-clock accounting. Export JSON backups regularly. Browser protection and local recovery points are not off-device backups.

Install or pin the app using your browser's menu. After one online visit it works offline. Updates never intentionally interrupt unfinished edits; older app windows may need to close before a storage upgrade.
